一、准备工作

你需要准备什么

  1. 一台 Windows 电脑（Mac 用户部分步骤不同，会标注）
  2. 网络连接
  3. 耐心（首次配置可能需要数小时，请预留充足时间）
  4. 一个 Agnes API Key（免费注册，后面会讲）

提前了解的概念

名词 简单解释
Git 下载代码的工具
Node.js 运行 JavaScript 程序的环境
Python 另一种编程语言环境
FFmpeg 处理视频的工具
API Key 像”密码”一样，让你能调用 Agnes 的服务
.env 文件 存放各种配置密码的文件
Trea AI 编程助手，帮你写代码和执行命令

五、配置 Agnes API

步骤 8：注册 Agnes 账号并获取 API Key

操作步骤：

  1. 打开浏览器，访问：https://platform.agnes-ai.com
  2. 点击”Sign Up”，用邮箱注册账号
  3. 登录后，进入 API Keys 页面
  4. 点击”Create Key”，复制生成的 Key（以 sk- 开头）
  5. 妥善保存，不要泄露给他人

踩坑提醒

  • 坑 1：注册后找不到 API Key 页面

    • 解决：通常在 Dashboard 或 Settings 菜单下，找”API”或”Keys”

  • 坑 2：Key 复制不完整

    • 解决：确保复制完整的 sk- 开头字符串，不要遗漏字符

  • 坑 3：Key 失效或过期

    • 解决：重新生成一个新的 Key，更新到 .env 文件中

八、部署方案选择与实测经验

本章节基于实测经验总结，帮助你选择最适合自己的方案。

方案一：完全零成本路径（真实影像素材 + Piper 本地 TTS + 免费音乐）

原理：

  • 图像：从 Pexels / Pixabay / Archive.org / NASA 免费下载
  • 视频片段：从上述平台免费下载
  • 旁白：Piper 本地离线合成（完全免费）
  • 音乐：Free Music Archive / Incompetech（免费）
  • 合成：Remotion + FFmpeg 本地渲染

成本：$0（完全免费）

适用场景：

  • 纪录片、纪实风格视频
  • 历史事件回顾
  • 城市人文短片
  • 自然科普内容
  • 预算为零的个人创作者

实测经验

优点：

  • 完全免费，不花一分钱
  • 真实影像有历史感和真实感
  • 素材来源丰富（Pexels 有数百万免费素材）

缺点与踩坑：

坑点 说明 严重程度
下载速度极慢 Pexels / Pixabay 服务器在国外，国内下载速度 50-200KB/s 高
文件大小不可控 NASA 素材默认提供 4K 原始版本，单文件 1-2GB 高
素材风格不统一 从多个平台下载的素材，色调、清晰度差异大 中
内容不可控 搜索”太空”可能返回不相关的素材 中
API 速率限制 Pexels 免费 API 每小时 200 请求 低

实测案例：制作”20世纪太空探索”90秒纪录片

  • 计划下载 8 张图像 + 4 段视频
  • 实际：NASA 4K 素材单文件 1.35GB，下载卡住
  • 总等待时间：>30 分钟（仍未完成）
  • 结论：免费方案”能用”但”不好用”

配置优化（如果坚持用）：

适合人群：

  • 网络环境好（有代理/VPN）
  • 对下载速度不敏感
  • 需要真实历史影像
  • 愿意手动筛选素材

方案二：Agnes 全模态路径（Agnes AI 生成所有素材 + Piper TTS + 免费音乐）

原理：

  • 图像：Agnes Image 2.1 Flash 生成
  • 视频片段：Agnes Video 2.0 生成
  • 旁白：Piper 本地 TTS
  • 音乐：免费音乐库
  • 合成：Remotion + FFmpeg 本地渲染

成本：

  • Agnes Image：~$0.03-0.15/张（6张约 $0.2-0.9）
  • Agnes Video：~$0.10/段（4段约 $0.4）
  • Piper：$0（本地免费）
  • 音乐：$0（免费库）
  • 总计：约 $0.6-1.3/条视频

注意：Agnes 目前处于推广期，实际费用可能更低或免费，请以官网最新政策为准。

适用场景：

  • 动画解说视频
  • 科幻/概念视频
  • 教育动画
  • 产品演示
  • 需要风格统一的视频

实测经验

优点：

  • 零下载等待，素材即时生成
  • 风格完全统一，色调一致
  • 内容完全可控，想要啥画面就有啥
  • 文件大小可控（图像 2-5MB，视频 5-10MB）
  • 不受网络波动影响

缺点：

  • 需要 Agnes API Key（免费注册）
  • 有轻微成本（但极低）
  • 视频生成有速率限制（8 RPM）
  • 单次视频片段约 5 秒，长视频需要分段

实测案例：制作”区块链工作原理”90秒动画

  • 生成 6 张图像：约 2 分钟，$0.3
  • 生成 4 段视频：约 4 分钟，$0.4
  • Piper 合成旁白：1 分钟，$0
  • 合成渲染：2 分钟
  • 总计：9 分钟，$0.7
  • 结论：速度快、质量高、成本可接受

适合人群：

  • 追求效率，不想等待下载
  • 需要风格统一的商业/教育内容
  • 愿意支付极低成本换取体验
  • 网络环境一般

方案三：商业 API 混合路径（FLUX/Kling/ElevenLabs 等付费服务）

原理：

  • 图像：FLUX via Replicate / Midjourney
  • 视频：Kling / Runway / Pika
  • 旁白：ElevenLabs（高质量）
  • 音乐：Udio / Suno（AI生成）
  • 合成：Remotion + FFmpeg

成本：

  • 图像：$0.5-2/张
  • 视频：$1-5/段
  • 旁白：$0.1-0.5
  • 音乐：$0.2-1
  • 总计：$3-10/条视频

适用场景：

  • 商业广告
  • 精品内容
  • 对质量要求极高的项目
  • 有预算的专业团队

实测经验

优点：

  • 质量最高（FLUX 图像、ElevenLabs 语音都是顶级）
  • 可控性最强
  • 适合商业交付

缺点：

  • 成本高，不适合个人频繁使用
  • 需要多个平台账号和密钥
  • 管理复杂（多个 API、多个账单）

适合人群：

  • 专业视频制作团队
  • 有明确预算的商业项目
  • 对质量极度敏感

方案四：混合方案（推荐）

原理：

  • 图像：Pexels / Pixabay 免费下载（文件小、速度快）
  • 视频片段：Agnes Video 2.0 生成（避免下载大文件）
  • 旁白：Piper 本地 TTS
  • 音乐：免费音乐库
  • 合成：Remotion + FFmpeg

成本：

  • 图像：$0（Pexels/Pixabay 免费）
  • 视频：~$0.4（Agnes 4段）
  • 旁白：$0（Piper 免费）
  • 音乐：$0（免费库）
  • 总计：约 $0.4/条视频

适用场景：

  • 所有通用场景（最平衡的方案）
  • 教程视频
  • 社交媒体内容
  • 播客视频
  • 个人创作

为什么推荐混合方案？——实测逻辑

经过对四种方案的实测对比，混合方案是最优解：

对比维度分析：

维度 方案一零成本 方案二Agnes全模态 方案三商业API 方案四混合
成本 $0 $0.6-1.3 $3-10 $0.4
速度 极慢（下载等待） 快 快 快
质量 中（依赖素材质量） 高（AI生成） 极高 高
可控性 低 高 极高 高
风格统一 差 优 优 良
网络依赖 高（国外服务器） 中（Agnes API） 高（多平台） 低
复杂度 中 低 高 低
适合小白 否 是 否 是

混合方案的核心优势：

  1. “扬长避短”的素材策略

    • 图像用免费下载：Pexels/Pixabay 的图像文件小（2-5MB）、下载快、质量高
    • 视频用 Agnes 生成：避免下载大文件，风格统一，内容可控
    • 旁白用 Piper：完全免费，本地运行，隐私安全

  2. 成本最低的可行方案

    • 比纯免费方案多花 $0.4，但节省 30 分钟以上等待时间
    • 时间成本 > 金钱成本（尤其对新手）

  3. 稳定性最好

    • 不依赖单一来源
    • 图像下载失败可 fallback 到 Agnes Image
    • Agnes 失败可用本地素材替代

  4. 学习曲线最平缓

    • 不需要处理复杂的下载配置
    • 不需要管理多个商业 API
    • 出错概率最低

实测案例：混合方案制作”20世纪太空探索”：

  • 图像：Pexels 搜索 “space rocket”、”astronaut”（8张，约 20MB，下载 1-2 分钟）
  • 视频：Agnes Video 生成 4 段 5 秒太空场景（约 3 分钟，$0.4）
  • 旁白：Piper 中文男声（1 分钟）
  • 音乐：Free Music Archive 史诗风格（30 秒下载）
  • 合成：Remotion + FFmpeg（2 分钟）

结果：

  • 总时间：8-10 分钟
  • 总成本：$0.4
  • 文件大小：输出约 50MB
  • 体验：流畅无卡顿，无需等待大文件下载

Q1: 你的预算是？

  • $0 → 方案一 或 方案四（混合约$0.4也接近零）
  • $0-1/条 → 方案四（推荐）
  • $1-5/条 → 方案二
  • $5+/条 → 方案三

Q2: 你的网络环境？

  • 很好（有代理/VPN，国外网站快）→ 方案一 可行
  • 一般（偶尔卡顿）→ 方案四（推荐）
  • 较差 → 方案二 或 方案四

Q3: 你对等待时间的容忍度？

  • 可以等 30 分钟+ → 方案一
  • 希望 10-15 分钟完成 → 方案四（推荐）
  • 希望 5-10 分钟完成 → 方案二

Q4: 你需要真实历史影像吗？

  • 必须真实（如历史纪录片）→ 方案一（优化配置）
  • 可以接受 AI 生成 → 方案二 或 方案四

Q5: 你是技术小白吗？

  • 是 → 方案四（推荐，出错最少）
  • 有一定技术能力 → 任意方案

十、常见问题速查

问题现象 可能原因 解决方法
git 命令无效 未安装或未加 PATH 重装 Git，勾选 PATH
node 命令无效 未安装或版本低 安装 Node.js 18+
python 命令无效 未加 PATH 重装 Python，勾选 PATH
ffmpeg 命令无效 未加环境变量 添加 bin 目录到 PATH
npm install 失败 网络问题 换 npm 镜像源
Agnes API 报错 Key 错误或超限 检查 Key，等待重试
视频渲染失败 FFmpeg 问题 检查路径和版本
找不到输出文件 路径错误 检查 output/ 目录
Piper 无中文 缺少中文模型 让 Trea 下载 zh_CN 模型
制作到一半卡住 内存/CPU不足 关闭其他程序，降低分辨率
下载速度极慢 国外服务器 切换素材源或改用 Agnes 生成
下载文件过大 未限制分辨率 添加 MAX_RESOLUTION=1920x1080
素材风格不统一 多平台混合 统一用 Agnes 生成，或后期调色

十一、重要提醒

安全提醒

  • API Key 不要泄露，不要上传到公开平台
  • .env 文件不要提交到 GitHub
  • 免费 tier 有速率限制，不要频繁调用

成本提醒

  • Agnes 目前处于推广期，实际费用可能更低或免费，请以官网最新政策为准
  • Piper 完全免费，本地运行
  • 免费素材库完全免费
  • 如需商业 API（ElevenLabs 等），注意控制预算

备份提醒

  • 重要的 .env 文件做好备份
  • 成品视频及时保存到其他位置
  • 项目配置可以复制到新电脑使用

版本提醒

  • 本教程基于 2026-06-18 的 OpenMontage 版本
  • 后续版本可能有变化，请关注官方更新

结语

OpenMontage 是一个强大的视频制作工具，但”工具的价值在于使用”。

对于非技术人员，我们的建议是：

  1. 先跑通：用混合方案做出第一个视频
  2. 再优化：根据需求调整方案（更省钱或更高质量）
  3. 最后精通：理解每个参数，自定义流程

记住：

  • 完成比完美更重要
  • 混合方案是最平衡的起点
  • 遇到问题先查第十部分的速查表
  • 还是解决不了，把错误信息复制给 Trea

4. 写文章的具体步骤

步骤1：创建文章

双击 新建文章.bat，输入标题如 我的读书笔记

步骤2：编辑文章

用任意文本编辑器打开生成的文件（如记事本、VS Code、Typora 等）：

在文件里写入内容，保存。

步骤3：预览效果

双击 本地预览.bat，浏览器打开 http://localhost:4000

步骤4：发布上线

双击 一键部署.bat，文章就发布到 GitHub Pages 了！

5. 常用写作工具推荐

工具 特点 下载地址
VS Code 免费、功能强大、支持预览 https://code.visualstudio.com/
Typora 所见即所得，写作体验好 https://typora.io/
记事本 Windows 自带，无需安装 系统自带

6. 注意事项

  1. 标题不能用特殊字符（如 : ? / 等），否则文件名可能出错
  2. 标签和分类 建议加在头部，方便文章归类
  3. 图片 放在 source/images/ 文件夹里，引用路径写 /images/xxx.jpg
  4. 保存后 需要重新生成网站才能看到效果
